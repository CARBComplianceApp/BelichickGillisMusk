CARB wrote a regulation. CARB did not write the operating system fleets need to stay legal. That is the service layer NorCal actually sells.

## What the law requires (lock)
- Almost all diesel / alt-fuel / hybrid >14,000 lb GVWR on CA public roads. Out-of-state plates included. Out-of-state motorhomes excluded.
- Three-part demonstration: report in CTC-VIS + pay annual fee in CTC-VIS + submit a passing test by the VIN deadline.
- Tester must be CARB-credentialed. Owner cannot self-certify.
- Most commercial units: **2× / year** now through Sep 2027.
- Ag (HD I/M definition) + CA rec/emergency MH: **1× / year** and stay annual after 2027.
- OBD-equipped only: **4× / year beginning 1 Oct 2027**.
- Passing test may be submitted up to 90 days before the deadline.
- Source of truth is the VIN in CTC-VIS, not a wall calendar and not a shop invoice.

EPA 2026-01-27 SIP partial disapproval does **not** remove OOS enforcement. CARB still tests out-of-state trucks that operate here.

## Gaps — mandated, not operationalized

| Mandate | What CARB shipped | What CARB did not ship | NorCal service hole |
|---|---|---|---|
| Semi-annual then quarterly cadence | Deadlines inside CTC-VIS + monthly email summary | No calendar event, no SMS, no +17w operating cadence, no yard booking | Every completed test → calendar +17w / 4 months. Ag/MH → +300d |
| Credentialed tester required | Exam + public tester list | No dispatch, no yard route, no Saturday coverage, no price | Mobile OBD $75 / OVI $199 at the yard |
| OBD vs OVI path | Engine-year rule + readiness page | No field decision aid when a yard mixes 2008 mixers and 2018 dumps | OBD/OVI split on booking. Charge the test performed |
| Non-OBD submission | Manual worksheet + tester upload | No owner-facing confirmation that upload landed | "If it is not uploaded, it did not happen." |
| OBD readiness / Not Ready | Technical criteria page | No shop-to-tester handoff. Battery pull / code-clear burns the 90-day window | Pass/fail explainer + retest path |
| Opacity cutpoints | 13 CCR § 2196.6 | Fleets still quote dead 40/55 PSIP table | Lock 5/20/30/40 + Level-3 VDECS = 5% |
| Ag definition | Narrow exclusive-ag + first-processing attestation | No field classifier. Paint on the door is not the class | Harvest post: ag annual vs haul 2× |
| 5-day pass | One per VIN per calendar year, CTC-VIS request, keep paper in cab | No reminder, no eligibility check at the gate, eCheck can take 7 days | Out-of-state / port-gate product. Not built |
| Freight facility access | Ports and intermodal railyards must verify compliance or use CARB data | No certificate-in-hand workflow for small carriers | Certificate + QR + public lookup assist |
| Freight brokers / contractors | Must contract only with compliant vehicles + keep records | No compliance-certificate API for brokers | Fleet attestation packet |
| Dealers | Separate dealer fact sheet | No delivery-day test product | New-unit OBD before first CA mile |
| Referee | Referral after NST / citation / no tester nearby / engine swap / fuel retrofit | Appointment + document pile. Vehicle must already be Ready | Referee prep, not referee itself |
| SB 210 DMV hold | Hold exists | No countdown from last pass to hold | +17w event is the countdown |
| Oct 2027 4× OBD | Date on the fact sheet | No tester-capacity plan, no fleet booking model, no device-throughput math | Yard model scales. Station model does not |
| Public lookup / certificate QR | Videos exist | Owners do not use them. Facilities do | Teach on pass/fail post + GBP |
| Off-road engines on-road | Opacity + visual regardless of year | Almost no public explainer | OVI path for farm/construction off-road that touches public roads |
| Alt-fuel non-OBD (2017-and-older) | Visual only, no opacity | Testers and owners still quote smoke | Do not sell a J1667 the rule does not ask for |

## What not to claim
- Do not say 4× testing is already in force. Start date is 1 Oct 2027, OBD only.
- Do not say ag is exempt. Ag is annual.
- Do not quote OVI $250 or MH $300. Live lock is $199 / $99 / $229.
- Do not treat EPA SIP language as an OOS loophole.
- Do not invent fleets or VINs in copy.
